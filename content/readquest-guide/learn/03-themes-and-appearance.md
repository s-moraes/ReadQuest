# Themes, Typography & Eye Comfort

Long reading sessions demand personalized ergonomics. ReadQuest gives you granular control over visual contrast, background warmth, and typography sizing.

---

## The Reader Appearance Modal

Tap the **Aa** (Format Size) button in the upper right corner of the Content Reader or navigate to the **Settings** screen to open appearance settings.

```text
+-------------------------------------------------------------+
| Reader Appearance                                           |
+-------------------------------------------------------------+
| Mode:  [ Light ]  [ Dark ]  [ System ]  [ Eye Comfort ]     |
|                                                             |
| Presets: [ Sepia ] [ Solarized Light ] [ Solarized Dark ]   |
|          [ Nord ]  [ High Contrast OLED ]                   |
|                                                             |
| Typography Scale:                                           |
|   A-  o-----------------O-----------  A+    (1.15x)         |
+-------------------------------------------------------------+
```

## Eye Comfort & Built-in Color Presets

ReadQuest features research-backed color palettes designed to minimize eye strain during daytime or late-night study:

| Preset Name | Background | Text Color | Recommended Use |
| :--- | :--- | :--- | :--- |
| **Sepia** | Warm Cream (`#F4ECD8`) | Deep Coffee (`#2C2416`) | Long reading sessions in ambient indoor lighting. |
| **Solarized Light** | Soft Off-White (`#FDF6E3`) | Indigo Slate (`#657B83`) | Reduced glare under bright fluorescent office lights. |
| **Solarized Dark** | Deep Teal (`#002B36`) | Crisp Ivory (`#839496`) | Night studying with minimal blue-light disruption. |
| **Pure OLED Black** | Pure Black (`#000000`) | Crisp White (`#FFFFFF`) | Maximum power efficiency on OLED/AMOLED displays. |

---

## Custom Palette Customization

You are not limited to presets. In the **Settings** screen, you can input arbitrary HEX values for both background and text:
- Enter valid `#RRGGBB` strings.
- The interface validates colors in real time and updates the entire application theme dynamically.

---

## Typography Scaling

Text scaling adjusts independently from system font settings:
- Use the slider to scale text from **0.8x** (dense view for small phone screens) up to **1.4x** (large text for tablets or relaxed reading).
- All Markdown nodes—including headers, list items, inline code, and table cells—scale proportionally.
- Your preferences persist across restarts using atomic local storage.
